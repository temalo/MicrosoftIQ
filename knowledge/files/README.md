# Contoso Events Conference Knowledge Base

This is the unstructured knowledge layer for the Contoso Events “Microsoft IQ” demo. Foundry IQ ingests these files to answer qualitative questions (speaker backgrounds, session and track descriptions, per-conference guides, the sponsor prospectus, the attendee FAQ and event policies), while the Fabric Data Agent answers the quantitative questions from the lakehouse tables.

## Contents

- `speaker-directory.md` — all speakers, expertise and bios
- `sponsor-prospectus.md` — sponsorship packages and the sponsor roster
- `attendee-faq.md` — registration, passes, virtual attendance, refunds
- `policies-and-guidelines.md` — code of conduct, recording, data use
- `conference-1-guide.md` — Data & Analytics Summit
- `conference-2-guide.md` — IT Infrastructure & Operations Summit
- `conference-3-guide.md` — Security & Risk Summit
